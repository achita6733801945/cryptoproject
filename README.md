# 🚀 Crypto Project (GitLab Pages)

## 📌 Project Overview
This project is a simple **Crypto Dashboard Web Application** deployed using GitLab Pages.

It demonstrates:
- Version Control using Git
- Repository management with GitLab
- CI/CD pipeline deployment
- Public web hosting

---

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- Git
- GitLab CI/CD
